# Regression

Predicts fictional house prices from floor area using linear regression, trained with gradient descent written from scratch in NumPy. The model is tested on houses it never saw during training, and its predictions are checked against scikit-learn's `LinearRegression`.

> **All data is synthetic.** It is generated by `data.py`, so these results say nothing about real house prices.

## How to run

Tested with Python 3.12 on Windows. From the project folder in PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy matplotlib scikit-learn
.\.venv\Scripts\python.exe main.py
```

On macOS or Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install numpy matplotlib scikit-learn
.venv/bin/python main.py
```

The results are printed to the terminal, and a chart is saved to `outputs/results.png`. The `outputs` folder is created automatically.

## What the model is

The model is a straight line:

```
predicted price = w × X + b
```

| Symbol | Meaning |
|---|---|
| `X` | Floor area in hundreds of m² (`area / 100`) |
| `w` | Weight (slope): dollars added per extra 100 m² |
| `b` | Bias (intercept): where the line crosses X = 0, not a real-world price |

Training means finding the values of `w` and `b` that make this line fit the training houses as closely as possible.

## How it works

### 1. Generate the data (`data.py`)

200 houses are created with floor areas spread evenly between 50 and 250 m². Their prices come from a known formula plus random noise:

```
price = 50,000 + 3,000 × area + noise      noise: normal distribution, mean 0, standard deviation $30,000
```

Because the true relationship is known, we can check whether the model rediscovers it: about $3,000 per m².

### 2. Split into training and test sets

The houses are shuffled. 160 are used for training and 40 are held back for testing. The model never learns from the test houses, so they measure how it performs on new data.

| Setting | Value |
|---|---|
| Data seed | 42 |
| Split seed | 7 |
| Train / test | 160 / 40 |

### 3. Scale the feature

Floor area is divided by 100, so `X` runs from about 0.5 to 2.5. This keeps each gradient step a sensible size. Without scaling, the same learning rate overshoots and training diverges.

### 4. Train with gradient descent (`model.py`)

The quantity being minimised is the **cost**, half the mean squared error over the training houses:

```
error = prediction − actual price
cost  = mean(error²) / 2
```

Training starts at `w = 0`, `b = 0` and repeats these steps 3,000 times:

1. Predict a price for every training house.
2. Calculate each error.
3. Calculate the gradients, which show which direction increases the cost:
   ```
   dw = mean(error × X)
   db = mean(error)
   ```
4. Step both parameters in the opposite direction (downhill):
   ```
   w = w − learning_rate × dw
   b = b − learning_rate × db
   ```

Both gradients are calculated from the same current `w` and `b` before either one is updated. Every step uses all 160 training houses (full-batch gradient descent).

| Hyperparameter | Value |
|---|---|
| Learning rate | 0.1 |
| Iterations | 3,000 |

### 5. Evaluate (`evaluate.py`)

- **MAE** (mean absolute error): the average dollar amount a prediction is off by.
- **RMSE** (root mean squared error): also in dollars, but large misses count more.
- **Baseline**: a model that ignores floor area and predicts the average training price for every house. The real model should beat it easily.
- **scikit-learn reference**: `LinearRegression` calculates the best-fitting line directly. If the gradient descent code is correct, the two models' predictions should match.

## Results

| Metric | Value |
|---|---|
| Learned `w` | 310,613.04 ($3,106.13 per m²; true value $3,000) |
| Learned `b` | 34,213.28 |
| Training MAE | $25,706.31 |
| Baseline test MAE | $165,875.68 |
| **Test MAE** | **$16,564.86** |
| Test RMSE | $22,489.94 |
| scikit-learn test MAE | $16,564.86 |
| Largest prediction gap vs scikit-learn | $0.0000 |
| Prediction for a 120 m² house | $406,948.92 |

- The model is about 10× more accurate than the baseline, so floor area is a strong predictor.
- Its predictions match scikit-learn's to four decimal places, so gradient descent reached the best possible line for this data.
- The intercept differs from $50,000 because of the random noise. Across the middle of the data, the fitted line and the true line almost coincide: at 150 m² they give $500,133 and $500,000.
- Test MAE is lower than training MAE by chance. With only 40 test houses, this split happened to contain fewer large misses.

### The chart

`outputs/results.png` has two panels:

- **Training cost** (left): the cost after each update, on a log scale. About 99% of the starting cost is gone after 10 updates, and the curve is flat after about 500. It never reaches zero because the noise can't be predicted from floor area.
- **Unseen examples** (right): the 40 test houses (dots) with the learned line through them.

## Project structure

| File | Contents |
|---|---|
| `data.py` | `make_data()` generates the houses; `split_data()` shuffles them and splits them into training and test sets |
| `model.py` | `predict()`, `compute_cost()`, `compute_gradients()` and the `fit()` training loop |
| `evaluate.py` | `mae()`, `rmse()` and `plot_results()` for the chart |
| `main.py` | Runs the full pipeline and prints the results |

## Limitations

- One feature, synthetic data, and a single train/test split.
- Predictions outside the 50–250 m² training range are extrapolations and are unreliable.
